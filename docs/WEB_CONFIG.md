# Web 配置控制台

db-hammer MCP 提供简洁的配置控制台，可用于在线管理连接和认证。

## 页面概览

- **配置编辑器**：显示当前 `ConfigManager` 配置，可直接编辑 JSON 并保存。
- **连接测试**：粘贴单个连接配置（type + params）后点击测试，实时验证数据库可用性。
- **状态提示**：操作结果会在页面底部显示成功或错误消息。

## 使用步骤

1. 启动服务并确保提供 API Key。
2. 浏览器访问 `http://<host>:<port>/`。
3. 首次访问提示输入 API Key，页面将缓存该值，后续请求自动携带。
4. 点击“刷新配置”查看当前配置；修改后点击“保存配置”提交到服务器。
5. 在“连接测试”区域填写独立配置片段，点击“测试连接”验证参数正确性。

## 安全建议

- 部署到公网时请强制 HTTPS，并限制 API Key 范围。
- 及时轮换 API Key，可通过 `AuthManager.register_api_key`/`revoke_api_key` 接口。
- 如需禁用匿名访问，确保配置中的 `allow_anonymous` 为 `false`。
